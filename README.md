Só Cardápio Online: API REST

Este é um projeto em desenvolvimento para a criação de uma API REST robusta e escalável, focada no gerenciamento de cardápios. O objetivo é fornecer uma solução flexível para que restaurantes e estabelecimentos possam gerenciar seus menus digitalmente.

Tecnologias

O projeto foi construído com as seguintes tecnologias para garantir alto desempenho, segurança e manutenibilidade:

    Back-end: Laravel (versão 12) para o desenvolvimento da API REST.

    Banco de Dados: MySQL para o armazenamento e gerenciamento das informações do cardápio.

    Front-end: JavaScript puro para o consumo da API, garantindo flexibilidade e performance.

Funcionalidades 

    Criação, leitura, atualização e exclusão de cardápios (CRUD).

    Gerenciamento de itens e categorias do menu.

    Endpoint para listagem de cardápios por restaurante.
